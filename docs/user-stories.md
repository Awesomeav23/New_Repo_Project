# User Stories

Format: **As a** <role>, **I can** <action>, **so that** <benefit>.
Roles: **visitor** (not logged in), **user** (logged in), **owner**, **editor** (can change the trip), **viewer** (read-only).

Priority: **P1** = must have for v1 · **P2** = should have · **P3** = nice to have.

## Accounts (Week 2–3)

| # | Story | Priority |
|---|---|---|
| A1 | As a visitor, I can sign up with email and password, so that I have my own account. | P1 |
| A2 | As a user, I can log in and log out, so that my trips stay private. | P1 |
| A3 | As a user, I can reset a forgotten password by email, so that I don't lose access. | P1 |
| A4 | As a user, I can set my name and avatar, so that friends recognize me in a trip. | P2 |

## Trips (Week 3)

| # | Story | Priority |
|---|---|---|
| T1 | As a user, I can create a trip with a name, destination and dates, so that planning has a home. | P1 |
| T2 | As a user, I can see all my trips split into upcoming and past, so that I find the right one fast. | P1 |
| T3 | As an owner, I can edit or delete a trip, so that details stay correct. | P1 |
| T4 | As an owner, I can add a cover image, so that trips are easy to tell apart. | P2 |

## Members (Week 4)

| # | Story | Priority |
|---|---|---|
| M1 | As an owner, I can share an invite link, so that friends can join without me typing their emails. | P1 |
| M2 | As a user, I can join a trip from an invite link, so that I can start planning with the group. | P1 |
| M3 | As an owner, I can make someone an editor or a viewer, so that I control who changes the plan. | P1 |
| M4 | As an owner, I can remove a member or hand ownership to someone else. | P2 |
| M5 | As a member, I can leave a trip I'm no longer part of. | P2 |

## Itinerary (Weeks 5–7)

| # | Story | Priority |
|---|---|---|
| I1 | As an editor, I can add an item (activity / food / transport / stay) to a day, so that the plan is written down. | P1 |
| I2 | As a member, I can see the itinerary grouped by day in time order. | P1 |
| I3 | As an editor, I can drag items to reorder them or move them to another day. | P1 |
| I4 | As an editor, I'm warned when two items overlap in time. | P2 |
| I5 | As a member, I can see the day's stops as pins on a map, so that I understand the route. | P1 |
| I6 | As an editor, I can search for a place to set an item's location. | P1 |

## Group decisions (Week 8)

| # | Story | Priority |
|---|---|---|
| D1 | As an editor, I can create a poll ("Which hotel?") with options and a deadline. | P1 |
| D2 | As a member, I can vote and see the results. | P1 |
| D3 | As an editor, I can turn a winning option into an itinerary item. | P2 |
| D4 | As a member, I can comment on an item or a poll, so that discussion stays in context. | P2 |

## Money (Weeks 9–10)

| # | Story | Priority |
|---|---|---|
| E1 | As a member, I can log an expense saying who paid and how it's split. | P1 |
| E2 | As a member, I can split an expense equally, by exact amounts, by percentage or by shares. | P1 |
| E3 | As a member, I can see who owes whom, with the fewest payments needed to settle up. | P1 |
| E4 | As a member, I can mark a debt as paid. | P1 |
| E5 | As a member, I can log an expense in a foreign currency and see it converted. | P2 |
| E6 | As an owner, I can set a trip budget and track spending against it. | P2 |
| E7 | As a member, I can attach a receipt photo to an expense. | P3 |

## Collaboration (Weeks 11–13)

| # | Story | Priority |
|---|---|---|
| C1 | As a member, I see other people's changes appear live without refreshing. | P1 |
| C2 | As a member, I can see who else is viewing the trip right now. | P3 |
| C3 | As a member, I get notified when I'm invited, a poll opens, or someone adds an expense that involves me. | P2 |
| C4 | As a member, I can see an activity feed of recent changes. | P2 |
| C5 | As a user, I can choose which notifications I get by email. | P3 |

## Packing + files (Week 12)

| # | Story | Priority |
|---|---|---|
| P1 | As a member, I can keep a shared packing list and a personal one. | P2 |
| P2 | As an editor, I can assign a shared item to someone ("Sam brings the speaker"). | P2 |
| P3 | As a member, I can upload tickets and bookings and open them later. | P2 |

## Extras (Weeks 13–14)

| # | Story | Priority |
|---|---|---|
| X1 | As a member, I can see the weather forecast for each trip day. | P3 |
| X2 | As a member, I can export the itinerary as a PDF or add it to my calendar. | P2 |
| X3 | As a member, I can install the app on my phone and view the trip offline. | P3 |
| X4 | As a user, I can switch to dark mode. | P3 |
